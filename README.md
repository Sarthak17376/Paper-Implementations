# Research Paper Implementations

A collection of independent, cleanroom implementations and reproducible benchmarks of published research papers.

Each project in this repository is implemented from first principles based on the mathematical formulations and algorithms described in the original publications, without relying on proprietary author code.

## Repository Structure

Each paper implementation is self-contained in its own directory with:
* An independent `README.md` detailing methodology, theoretical assumptions, and instructions
* Standalone execution scripts and interactive notebooks
* Checkpointing, logging, and evaluation utilities
